可能会被喷，但是全是干货 （面试篇）

上一篇忘记自我介绍 我中英母语，本科期间拿过四段美国 独角兽/大厂实习，现任顶级独角兽 senior， 也面试过30+ intern/ng 我可以自信地说很少有人比我更懂怎么拿到intern/ng offer。 现在讲讲面试， Intern/New Grad面试无非就是 technical + bq + System Design（限ng), 其中technical的重要性占比达到70%，behavioral占30%。因为technical一旦挂了，bq轮可能都没有 所以 一旦拿到面试后 Technical 1. 把neetcode 150 刷透 2. 去一亩三分地找公司的题库（可以在淘宝上买账号），很多公司题目都不会换，出来出去就那几题（点名那几个独角兽） 3. Leetcode tag题可刷可不刷。 4. Leetcode周赛强烈推荐，面试难度基本也就1-3题，建议把自己录下来，边说边写，把自己的思路说出来然后复盘。 5. 最近出现的一些AI 辅助面试 不做评价，现在主流依旧是leetcode题。 BQ（行为面试） 1. 多对着gpt 练练，临近时跟真人mock一两次 2. 把每个可能出现的核心主题准备一个故事， challenge， conflict，mistake，collaboration，above and beyond… 很多同学说自己英语不好，硬背总会吧。再不济，面试前贴几个sticky note在电脑上，跟面试官说记了笔记也可以。 System Design（ng only） 1. NG system design 的 bar 很低， 只要能大概扯点东西出来都算过，面试前一周看看hello interview就够了。 更重要的是 不要提前焦虑没发生的事情，有很多同学简历都没投几个，就在担心bq过不了，sd过不了，问简历怎么办… 我只能说先拿到面试再说，拿到面试后，所有人都55开。详情看上一篇帖子。 需要mock ，修改简历，或者全程辅导可以找我 （再打个广告） #北美求职 #北美ng求职 #北美intern #tech求职
