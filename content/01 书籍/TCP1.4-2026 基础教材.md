## H.A.R.N.E.S.S. Workflow

### H - Highlight

Only highlight:

- formulas
- limitations and phase-outs
- exceptions
- confusing comparisons
- example-solving steps

### A - Ask

For each subsection, ask at least one exam-style question:

- When does this rule apply?
- What are the exceptions?
- What numerical threshold matters?
- How could an exam question hide the key condition?

### R - Rephrase

Rewrite textbook language into clear rule statements:

- If X occurs, Y is generally required.
- Z is allowed only when A, B, and C are satisfied.
- The key is not calculation first; it is eligibility first.

### N - Network

Each important rule should link to:

- one topic: [[美国税法 TCP]]
- one module
- one example or mistake card

### E - Extract

Extract three types of cards:

- Rule card: definition, conditions, exceptions
- Calculation card: formula, steps, numerical thresholds
- Comparison card: differences between similar concepts

### S - Synthesize

After each module, write a one-page module summary:

- what the module is about
- high-frequency rules
- high-frequency numbers
- common traps
- typical question patterns

### S - Ship

Each week, create one learning output:

- one-page cheat sheet
- Anki-style question set
- mistake review
- topic summary
