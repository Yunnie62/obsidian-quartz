# Consolidated Return Affiliated Group

## Core Rule

An affiliated group may file a consolidated return when the parent meets the ownership requirements and all members are eligible and consent.

## Ownership Test

The parent generally must own at least 80% of voting power and at least 80% of value.

## Chinese Note

- 易错提醒：80% voting power 和 80% value 两个都要看。
