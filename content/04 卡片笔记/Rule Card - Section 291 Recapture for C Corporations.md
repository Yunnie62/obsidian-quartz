# Section 291 Recapture for C Corporations

## Core Rule

Section 291 can require C corporations to recognize additional ordinary income on certain real property dispositions beyond the normal Section 1250 recapture.

## Chinese Note

- 易错提醒：Section 291 is a C corporation-specific recapture rule.
