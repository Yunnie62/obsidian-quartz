# Consolidated Return Liability and Compliance

## Core Rule

Each member of a consolidated group is jointly and severally liable for the group's consolidated tax liability, penalties, and interest.

## Chinese Note

- 易错提醒：合并申报不是 parent 自己负责，members 也可能 jointly and severally liable。
