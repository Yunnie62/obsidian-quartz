# TCP 2 Module 3 - Consolidated Tax Returns

## Module Purpose

This module explains when affiliated corporations may file a consolidated return and how consolidated taxable income, compliance, tax years, accounting methods, and liability are handled.

## High-Yield Rules

- Filing a consolidated return is a privilege for eligible affiliated groups.
- The parent must generally own at least 80% of voting power and at least 80% of value.
- S corporations, foreign corporations, most REITs, some insurance companies, and most exempt organizations generally cannot join.
- Each member is jointly and severally liable for consolidated tax liability, penalties, and interest.
